# Estructura del proyecto

- lib/app.dart: tema y arranque de providers
- lib/controllers: logica de orquestacion y settings
- lib/models: modelos de configuracion y datos
- lib/services: Twitch IRC, TTS, STT, VibeVoice, websockets
- lib/ui: pantallas y widgets
- lib/utils: utilidades (levenshtein, filtros, rate limiter)
- web/promo/index.html: landing promocional
- web/promo/manual.html: manual HTML de instrucciones
- docs/RESEARCH.md: fuentes de documentacion
