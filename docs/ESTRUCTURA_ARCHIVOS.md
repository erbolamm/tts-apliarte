# Estructura de archivos

## Raiz
- `README.md`: descripcion y bloque final obligatorio.
- `ESTADO.md`: resumen de cambios y estado actual.

## lib
- `app.dart`: providers + tema.
- `main.dart`: entrypoint.
- `controllers/`: logica principal y settings.
- `models/`: settings y modelos de datos.
- `services/`: Twitch IRC, TTS, STT, VibeVoice, websockets.
- `ui/`: pantallas.
- `ui/widgets/`: componentes.
- `utils/`: helpers (levenshtein, filtros, rate limiter).

## docs
- `RESEARCH.md`: fuentes.
- `STRUCTURE.md`: resumen de estructura.
- `MANUAL_TECNICO.md`: guia detallada.
- `CONFIGURACION.md`: claves de config.
- `API_WEBSOCKETS.md`: contrato de WS.
- `INTEGRACION_VIBEVOICE.md`: VibeVoice.
- `GUIA_RAPIDA.md`: checklist.

## web
- `web/promo/index.html`: landing promocional.
- `web/promo/manual.html`: manual HTML.
