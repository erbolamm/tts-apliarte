Lo que hace distinto a TTS ApliArte

Traduccion inteligente

Auto traduccion con API configurable y envio opcional al canal.

Filtro anti spam

Levenshtein por usuario y global para evitar mensajes repetidos.

Comandos por voz

Overlay editable

Generador de URL con estilos tipo tts.bot para OBS.

Pipeline en 4 pasos
1. Twitch IRC escucha tu chat en tiempo real.
2. Filtros limpian menciones, emotes y spam.
3. Traduccion auto (si procede) y envio opcional.
4. TTS System o VibeVoice reproduce con claridad.
