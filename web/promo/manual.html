Manual rapido de TTS ApliArte

Guia practica para montar traduccion y TTS en Twitch en menos de 10 minutos.

Paso 1

Arranque local

Desde la carpeta del proyecto:

flutter pub get flutter run -d macos
Paso 2

Credenciales de Twitch

  • Username: tu usuario de Twitch.
  • OAuth Token: token de chat en formato oauth:xxxxx.
  • Channel: canal que quieres leer.
Paso 3

Traduccion en vivo

  • Source Language: deja auto para detectar idioma.
  • Dest Language: ejemplo es, en, pt.
  • Translation API Base URL: servidor compatible (ej: LibreTranslate).
  • Opcional: enviar traducciones al chat.
Paso 4

Motor de voz

System TTS

Usa las voces del sistema operativo. Selecciona idioma y voz.

VibeVoice

Motor neural. Requiere servidor local en ws://localhost:3000.

Ejemplo para iniciar VibeVoice:

python -m uvicorn demo.web.app:app --reload --port 3000

Para pruebas rapidas:

python -m uvicorn demo.web.fake_server:app --reload --port 3000
Paso 5

Mic y comandos de voz

  • Activa Use Speech Recognition.
  • Poof: para cortar TTS actual.
  • Ban: corta y reproduce confirmacion.
  • Pausa TTS cuando hablas para evitar solapado.
Paso 6

Overlay para OBS

  • En la seccion Overlay copia la URL generada.
  • En OBS usa "Browser Source" y pega la URL.
  • Personaliza colores y tipografia en el panel.
Problemas tipicos
  • Sin audio: revisa el motor TTS y el dispositivo de salida.
  • No conecta Twitch: token OAuth incorrecto o canal mal escrito.
  • Sin traduccion: API no disponible o idioma destino en auto.
  • VibeVoice mudo: confirma sample rate 24000 y servidor activo.
Checklist rapido
  1. Token OAuth correcto.
  2. Conectado a Twitch.
  3. Idioma destino definido.
  4. Motor TTS elegido.
  5. Overlay listo si usas OBS.
