Tu chat en vivo, traducido y hablado al instante

Voz clara y traducción en tiempo real para Twitch.

Convierte los mensajes del chat en voz natural del sistema, filtra el spam repetitivo y traduce automáticamente para que nunca pierdas el ritmo de tu directo.

📦 Ver Repositorio en GitHub 📺 Canal de Twitch

⚡ Ingeniería y Especificaciones Reales

⚡

IRC Nativo sobre WebSockets

Conexión directa y ligera a los servidores de Twitch Chat (IRC) sin intermediarios lentos ni lag acumulado.

🗣️

System TTS Multi-Voz

Uso de los sintetizadores de voz nativos del sistema operativo (`flutter_tts`) sin cuotas por palabra ni consumo de API externa.

🛡️

Filtro Anti-Spam & Levenshtein

Detección inteligente de mensajes repetitivos y cadenas duplicadas para proteger tus oídos de bombardeos en el chat.

🌐

Traducción en Tiempo Real

Integración con MyMemory API y opciones para servidores de traducción locales o cloud sin vendor-lockin.

🎨

Kit de Marca ApliArte Dark

Diseño premium de alto contraste (#1A1A1A / #303030 / #5ECEF5) pensado para no cansar la vista en cabina de streaming.

🔒

Zero Data Collection

Tus tokens y configuraciones se guardan 100% en tu máquina local. Ningún servidor externo registra tus conversaciones.

🧭 Cómo Funciona Paso a Paso

1

Inicia la App

Abre TTS ApliArte en tu ordenador (macOS, Windows o Linux) o dispositivo Android.

2

Conecta tu Cuenta de Twitch

Pulsa "Login Twitch" para autorizar la lectura de tu chat con el flujo OAuth seguro en tu navegador.

3

Selecciona el Idioma y Voz

Elige tu sintetizador preferido, ajusta el volumen, velocidad y tono a tu gusto desde los deslizadores.

4

Configura el Filtro de Spam

Activa el límite de caracteres y similitud para silenciar automáticamente usuarios que repiten el mismo mensaje.

5

Modera con Comandos Rápidos

Usa los botones integrados para lanzar /shoutout a los streamers que visitan tu directo o enviar comandos estándar.

6

Disfruta del Directo

Escucha a tu comunidad por los auriculares mientras juegas o programas sin tener que mirar la pantalla del chat todo el tiempo.

¿Se guardan mis contraseñas o tokens en algún servidor?

No. El token OAuth se conserva exclusivamente en el almacenamiento local seguro de tu aplicación (`shared_preferences`).

¿Puedo usarlo sin cuenta de desarrollador de Twitch?

Sí. La app utiliza el Client ID público de ApliArte con el flujo de autorización estándar para creadores.

💻 Instalación Rápida por Terminal

CLONAR Y EJECUTAR (FLUTTER) MULTI-PLATAFORMA
git clone https://github.com/erbolamm/tts-apliarte.git && cd tts-apliarte && flutter run
CONSTRUCCIÓN WEB / ESCRITORIO PRODUCCIÓN
flutter build macos # O usa: flutter build windows / flutter build linux / flutter build web
